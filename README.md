# Inception-of-Things

This repository contains the implementation of the Inception-of-Things subject, organized into three mandatory parts and an optional bonus.

## Structure

- `p1/` – Part 1: K3s with Vagrant and two virtual machines.
- `p2/` – Part 2: K3s with three applications and an Ingress.
- `p3/` – Part 3: K3d, ArgoCD, and GitOps deployment from GitHub.
- `bonus/` – Optional GitLab integration for Part 3.
- `docs/` – Architecture and per-part documentation.

## Getting started

1. Clone this repository.
2. Read `docs/architecture.md` for a high-level overview.
3. Follow `docs/part1.md`, `docs/part2.md`, and `docs/part3.md` to set up each part.
